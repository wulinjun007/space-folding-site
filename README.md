# 空间折叠设计手册 · Space-Folding Design Handbook

一个讲解「空间折叠设计」的静态知识网站：用同一套模型（**几何 / 机构 / 时序**三层）解释**室内、汽车、家具**三个领域的折叠设计，重点说明每个领域的知识点与设计思路细节。

## 本地运行

纯静态站点，无构建步骤、无外部依赖（字体/图标均为系统字体与内联 SVG，可完全离线）。

方式一：直接用浏览器打开 `index.html`。

方式二（推荐，体验与线上一致）：

```bash
cd space-folding-site
python3 -m http.server 8412
# 打开 http://localhost:8412/
```

## 页面结构

| 文件 | 内容 |
| --- | --- |
| `index.html` | 总览：空间折叠定义、三层折叠模型（几何/机构/时序）、三大领域导航、阅读路径 |
| `methodology.html` | 通用方法论：第一性原理与状态机、六种基本运动、五类机构库、几何要点（包络/折叠比）、时序设计法（切换成本/主态）、安全耐久、**跨领域原则映射表**、术语表 |
| `interior.html` | 室内：四种折叠维度（平面/竖向/视觉/时序）、24h 时序交互图、共享空间对判定六步法、尺寸基准表、案例（Domestic Transformer / Cabanon / 和室）、12 条检查清单 |
| `automotive.html` | 汽车：布置基础（H 点/轮包/纯平地台）、座椅折叠五级体系、座椅三态交互演示、场景定义空间五步法、案例（本田魔术座椅 / Model Y / 场景化 MPV）、10 条检查清单 |
| `furniture.html` | 家具：品类五族谱系、墨菲床机构详解（气弹簧/连杆/过死点）、频次×时长矩阵、收拢态美学、案例（Clei / Ori / IKEA PS / 瓦楞纸家具）、10 条检查清单 |

## 技术说明

- `css/style.css` — 设计系统：纸感米白 + 墨蓝 + 折纸朱红，知识点（蓝）/ 思路细节（朱红）双区块样式，全部响应式（960px / 640px 两档断点）。
- `js/main.js` — 交互：滚动揭示、移动端菜单、检查清单 localStorage 持久化（按页面存储）、状态演示切换、时间轴片段点击联动。
- 所有图示为手绘内联 SVG（状态机、四杆/剪式机构、折叠隔断平面图、座椅三态、墨菲床机构、蝴蝶板伸缩桌）。
